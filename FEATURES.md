# Paint Buddy Features

## Shipped

- Menu-bar agent app (no Dock by default)
- Clipboard monitoring for color tokens (hex, rgb, rgba, named CSS colors, tuples)
- Configurable capture formats and preferred copy format
- Color history in menu bar, main window, and floating always-on-top palette
- Favorites palette (separate from history) with main-window list and floating always-on-top window
- Cross-open between history and favorites floating panels
- Click-to-pick eyedropper (`NSColorSampler`) — cursor changes, click saves once
- Per-channel copy for RGB / RGBA (R, G, B, A)
- Suggested darker / lighter / harmony colors on the detail pane
- Configurable floating grid swatch size (columns follow window width)
- Pause monitoring, launch at login, appearance / accent
- History limits and erase-all

## Out of scope (v1)

- Continuous / always-on cursor sampling
- Image OCR color extraction
